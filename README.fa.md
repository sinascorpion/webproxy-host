# Webproxy Host

[English](README.md)

پنل سبک Go برای پروکسی وب تلگرام؛ ورود فقط با رمز در مسیر اختصاصی، صفحهٔ
عمومی جدا، چند دامنه و Secret و تگ اسپانسر، و نمایش لینک‌های کامل اتصال.
برنامه به root، دیتابیس، Node.js، NGINX یا نصب‌کنندهٔ اوبونتو نیاز ندارد.

## نصب روی هاست برنامه

هاست لینوکسی amd64 یا arm64 باید اجرای پروکسی، پردازش هسته، فضای پایدار،
اتصال خروجی به تلگرام، HTTPS عمومی، WebSocket و درخواست‌های طولانی را پشتیبانی کند.
دامنهٔ عمومی روی HTTPS پورت ۴۴۳ باید به پورت HTTP اختصاصی برنامه وصل شود.

این رپو را به‌عنوان Source انتخاب کن. محیط اجرا **Go** و دستور شروع:

```sh
sh start.sh
```

این دستور فایل اجرایی آماده را با بررسی checksum دریافت می‌کند؛ روی هاست
کوچک نیازی به کامپایل Go یا Rust نیست.

در Environment تنظیم کن:

| متغیر | مقدار |
| --- | --- |
| `ADMIN_PASSWORD` | رمز تصادفی قوی با حداقل ۱۲ کاراکتر |
| `PUBLIC_URL` | آدرس کامل HTTPS اختصاص‌یافته به هاست، بدون مسیر اضافی |
| `DATA_DIR` | پوشهٔ قابل‌نوشتن و پایدار؛ پیش‌فرض `./data` |
| `ADMIN_UID` | اختیاری؛ مسیر ۱۶ تا ۸۰ کاراکتری با حروف، عدد، `_` یا `-` |

اگر UID وارد نکنی، خود برنامه آن را می‌سازد و نگه می‌دارد. آدرس پنل در Console
نمایش داده می‌شود؛ ورود همچنان رمز می‌خواهد. پورت اختصاصی هاست از `SERVER_PORT`
یا `PORT` خوانده می‌شود. قبل از Deploy هیچ پروکسی‌ای اجرا نمی‌شود.

## استفاده

۱. همان نام دامنهٔ اختصاص‌یافته به هاست را وارد کن. برای دامنهٔ دیگر، ابتدا
DNS، HTTPS و اتصال آن به برنامه را در قسمت Domains هاست آماده کن.

۲. Secret قبلی را وارد کن یا Generate بزن. Secret با ۳۲ کاراکتر هگز و پیشوند
اختیاری `dd` پذیرفته می‌شود.

۳. در صورت نیاز، بعد از تعیین Secret آن را در @MTProxybot ثبت کن و تگ را وارد کن.

۴. Deploy proxy را بزن و پس از آماده‌شدن هسته، از Connection links لینک کامل را بردار.

می‌توانی پروفایل‌های بیشتری اضافه کنی. Secret مشترک باید تگ یکسان داشته باشد.
با ثابت‌ماندن دامنه و Secret، لینک کاربران ثابت می‌ماند. تغییر تنظیمات اتصال‌های
فعال را مجدداً برقرار می‌کند. Disable proxy تنظیمات را نگه می‌دارد و بعد از ری‌استارت
برنامه هم غیرفعال می‌ماند.

پنل DNS یا SSL نمی‌سازد و نمی‌تواند زیر دامنهٔ متعلق به ارائه‌دهنده، ساب‌دامنهٔ دلخواه
ایجاد کند. اضافه‌کردن نام در پنل فقط تنظیم پروکسی است. وضعیت Core ready به معنی آماده‌بودن
هسته است؛ مسیر عمومی HTTPS و WebSocket هاست هم باید درست باشد.

از `DATA_DIR` بک‌آپ بگیر؛ این پوشه حاوی Secret و تنظیمات خصوصی است و نباید وارد گیت شود.
رمز را فقط در Environment نگه دار. تغییر رمز به ری‌استارت نیاز دارد.

**نصب زنده روی Botkeep هنوز تست نشده**؛ هنگام آماده‌سازی، ظرفیت ایجاد سرور موجود نبود.
این سورس برای هاست‌های برنامه به‌صورت عمومی آماده شده و سازگاری و مجوز اجرای آن
روی هر ارائه‌دهنده باید بررسی شود.
